Quy tắc API

  • API nội bộ phải yêu cầu authentication, trừ endpoint public được ghi rõ.
  • Backend phải enforce authorization, frontend chỉ hỗ trợ ẩn/disable action.
  • Input phải validate qua DTO.
  • Không trả về sensitive field như passwordHash hoặc token secret.
