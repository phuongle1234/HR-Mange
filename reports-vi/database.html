Quy tắc migration

Dữ liệu dùng PostgreSQL, ORM dùng Prisma. Mọi thay đổi schema phải đi qua Prisma migration và cập nhật tài liệu database nếu thay đổi ảnh hưởng behavior đã mô tả.
